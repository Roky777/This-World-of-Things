# This World of Things Sorter

Browser sorting game built from the shared conveyor template.

## Levels

1. Seeing Through Things — Transparent, Translucent, Opaque
2. What Is It Made Of? — Wood, Metal, Glass, Plastic
3. Natural or Artificial Things — Natural, Artificial

Every level uses the supplied Grade 3 object artwork and keeps four evenly spaced objects visible with continuous off-screen spawning. The first level retains the forced, skippable tutorial and progress is saved locally.
